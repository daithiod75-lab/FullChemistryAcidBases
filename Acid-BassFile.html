1. 酸と塩基とは？

酸（さん）

水に溶けたときに水素イオン（H⁺）を生じる物質。例：塩酸・硫酸・酢酸。

塩基（えんき）

水素イオン（H⁺）を受け取る物質。アルカリは水溶液中でOH⁻を生じる塩基。

アレニウスの定義

酸は水溶液中でH⁺を生じ、塩基は水溶液中でOH⁻を生じます。

HCl → H⁺ + Cl⁻
NaOH → Na⁺ + OH⁻

ブレンステッド・ローリーの定義

酸はH⁺を与え、塩基はH⁺を受け取ります。アンモニアも塩基として説明できます。

NH₃ + H₂O ⇌ NH₄⁺ + OH⁻
水溶液中のH⁺は実際にはH₃O⁺などの形で存在しますが、高校ではH⁺と簡略表記することが多いです。

2. pHと酸性・アルカリ性

pHは水溶液の酸性・アルカリ性の程度を表します。約25℃では、pHが7未満なら酸性、7なら中性、7より大きければアルカリ性です。

0（強い酸性側）7（中性）14（強いアルカリ性側）

中性

[H⁺] = 1 × 10⁻⁷ mol/L

pH = −log₁₀[H⁺]

pHが1下がると、水素イオン濃度は10倍になります。pH 3の水溶液の水素イオン濃度は、pH 4の10倍です。

身近な物質のpH（目安）

物質pHの目安
胃酸1〜2
レモン汁約2
食酢2〜3
純水（25℃）7
重曹水8〜9
石けん水9〜11
家庭用漂白剤11〜13
実際のpHは製品や濃度によって異なります。pHは0〜14の範囲外になる場合もあります。

3. 中和反応

中和反応とは酸と塩基が反応することです。代表的な中和反応では塩と水が生成されます。

酸 ＋ 塩基 → 塩 ＋ 水
HCl + NaOH → NaCl + H₂O
H⁺ + OH⁻ → H₂O

塩酸と水酸化ナトリウムの反応では、塩化ナトリウムと水ができます。

注意：中和が起きても、必ずpH 7になるわけではありません。酸・塩基の強さや量、生成した塩によって変わります。

反応を確かめよう

このモデルはH⁺とOH⁻の量的な関係を示す単純化したものです。実際の最終pHを計算するものではありません。

4. 強酸・弱酸・強塩基・弱塩基

酸や塩基の強さは、主に水溶液中でどの程度電離するかによって決まります。

分類例
強酸塩酸 HCl、硝酸 HNO₃
弱酸酢酸 CH₃COOH、炭酸 H₂CO₃
強塩基水酸化ナトリウム NaOH、水酸化カリウム KOH
弱塩基アンモニア NH₃
HCl → H⁺ + Cl⁻

塩酸は薄い水溶液中でほぼ完全に電離します。

CH₃COOH ⇌ CH₃COO⁻ + H⁺

酢酸は一部だけ電離します。両向きの矢印は化学平衡を表します。

「強さ」と「濃度」は別！強酸でも薄い水溶液なら、濃い弱酸よりpHが高い場合があります。

6. 中和滴定

濃度が分かっている酸または塩基を使い、濃度不明の水溶液の濃度を求めます。

例題

濃度不明の塩酸20.0 mLを中和するために、0.100 mol/Lの水酸化ナトリウム水溶液16.0 mLを使用しました。

HCl + NaOH → NaCl + H₂O
C酸 × 20.0 = 0.100 × 16.0
C酸 = 0.0800 mol/L

中和滴定の計算機

酸の価数 × 酸のモル濃度 × 酸の体積 ＝ 塩基の価数 × 塩基のモル濃度 × 塩基の体積

値を入力して計算してください。
この計算は、酸と塩基が化学量論的にちょうど反応した当量点を想定します。終点は指示薬などによって実験上判断する点です。

10. まとめ・酸と塩基の価数

高校の「化学基礎」で身につけたい力は、酸と塩基の区別、電離、強酸・弱酸の違い、pH計算、中和反応式、モル濃度、中和滴定の計算です。

酸・塩基の価数

塩酸は1価の酸、硫酸は2価の酸です。

HCl → H⁺ + Cl⁻
H₂SO₄ → 2H⁺ + SO₄²⁻

水酸化ナトリウムは1価の塩基、水酸化カルシウムは2価の塩基です。

NaOH → Na⁺ + OH⁻
Ca(OH)₂ → Ca²⁺ + 2OH⁻
H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O

硫酸1 molを完全に中和するには、水酸化ナトリウム2 molが必要です。

a Ca Va = b Cb Vb

aは酸の価数、bは塩基の価数、Cはモル濃度、Vは体積です。体積の単位はそろえます。

重要な5つのポイント

  1. 酸は水中でH⁺を生じ、アルカリはOH⁻を生じます。
  2. pHは水溶液の酸性・アルカリ性の程度を表します。
  3. 中和では酸と塩基が反応し、代表的な場合には塩と水ができます。
  4. 酸・塩基の強さと水溶液の濃度は別の概念です。
  5. 中和滴定では、価数と物質量の関係から未知の濃度を求めます。
安全上の注意：実験では保護眼鏡を着用し、薬品を味見したり、直接触れたりしないでください。酸と塩基、漂白剤などの家庭用薬品を勝手に混ぜないでください。
